# 🛡️ PrediSafe AI

## AI-Powered Natural Disaster Risk Prediction & Early Warning System

PrediSafe AI is an AI-powered disaster risk prediction and early warning system designed to identify potential flood and landslide risks using environmental signals and machine learning.

The system analyzes factors such as rainfall, humidity, soil moisture, river conditions, terrain characteristics and historical disaster information to generate a risk score and risk level.

### Key Features

- 🌊 Flood Risk Prediction
- ⛰️ Landslide Risk Prediction
- 📊 Risk Score (0–100)
- 🤖 Explainable AI Risk Factors
- 📈 Risk Trend Analysis
- 🚨 Early Warning & Emergency Mode
- 🆘 SOS Workflow
- 📍 Location Detection
- 🏥 Nearby Safe Places
- 🚑 Emergency Services
- 🌦️ Live Environmental Data

### Technology Stack

- Python
- Flask
- Machine Learning
- Scikit-learn
- Pandas
- NumPy
- JavaScript
- Leaflet Maps
- Open-Meteo API
- OpenStreetMap

### Project Purpose

PrediSafe AI aims to provide an early decision-support system that can help users understand changing disaster risk and take preventive safety actions before conditions become critical.

> Note: This prototype uses demo/synthetic training data and is intended for demonstration and decision support, not as an official emergency-warning authority.
